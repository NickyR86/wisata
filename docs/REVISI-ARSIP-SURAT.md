# Revisi arsip, riwayat, dan surat — 23 Oktober 2026

Arsip menggunakan daftar–detail: identitas kegiatan, lokasi, nominal, penyerahan, penerima, tanda tangan, nomor dan sumber dokumen, pembagian salinan pemohon/internal, serta berkas persyaratan. Unduhan metadata tetap dilabeli metadata; belum berupa paket berkas PDF.

Riwayat dipaginasi per aktivitas (20 baris), bukan per permohonan. Nomor urut berlanjut antarhalaman; seluruh aktivitas diurutkan berdasarkan waktu. Filter waktu memakai tanggal aktivitas. Pencarian mencakup tindakan dan catatan, disertai filter peran. Rekap CSV yang tersedia masih rekap permohonan.

Satu komponen surat utuh dipakai pada editor, verifikasi, rilis, tanda tangan, dan pratinjau final: kop, nomor demo, identitas, narasi, ketentuan, tanggal, jabatan dan tanda tangan simulasi. Dokumen belum ditandatangani tetap diberi status draft.

Validasi: 28 pemeriksaan integrasi revisi lulus. Arsip, riwayat dan surat rilis diperiksa melalui browser desktop. Screenshot disimpan di docs/screenshots. Hasil cetak native belum diperiksa ulang pada revisi ini.
