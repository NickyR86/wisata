# Revisi format keuangan
SKRD menggunakan tabel menyatu berdasarkan foto: masa/tahun terpisah, nomor urut, lima baris per rincian, kotak kode rekening, ringkasan ketetapan/sanksi, perhatian, tanda tangan a.n. Kepala Dinas, dan tanda terima.
STBP menggunakan daftar a–g; STS daftar 1–5 dan dua penandatangan. Label Penerimaan Tanggal mengikuti foto sumber.
Total rincian harus cocok dengan tagihan. Keringanan mengikuti keputusan tersimpan. Denda/kenaikan masih nol, belum mendukung penetapan sanksi. Nama penandatangan fiktif, tanda tangan belum elektronik sungguhan.
Pengujian: 20 permintaan integrasi lulus, pratinjau JS/tambah-hapus rincian/masa-tahun lulus. Ketiga contoh diperiksa dengan CSS cetak A4; belum printer fisik. Narasi panjang atau banyak rincian dapat membutuhkan beberapa halaman.
