# Ringkasan penyerahan frontend

**Proyek:** SIAP-Wisata — administrasi permohonan kegiatan Dinas Pariwisata.

**Teknologi:** Laravel 12, Blade, Bootstrap 5.3.8, CSS dan JavaScript. Tidak menggunakan React.

**Status:** frontend interaktif dengan data contoh dan simulasi proses menggunakan sesi Laravel.

Halaman tersedia untuk Sekretariat/Bagian Umum, Kepala Bidang, Petugas Layanan, Sekretaris, Bendahara, Kepala Dinas, dan Admin. Layout serta komponen dipakai bersama; tindakan menyesuaikan role dan tahap.

Demo dapat memperagakan satu permohonan dari pendaftaran, review, penyusunan/revisi draft, verifikasi, rilis, retribusi, pembayaran, tanda tangan, penyerahan, sampai arsip. Tersedia agenda, rekap, dan preview/cetak dokumen contoh.

**Belum termasuk backend produksi:** autentikasi akun, database, penomoran surat resmi, tanda tangan tersertifikasi, pengiriman pesan, integrasi pembayaran, jadwal bentrok, dan kalender libur. Kewenangan keputusan keringanan tidak ditentukan sepihak; digunakan fixture keputusan disetujui untuk memperagakan potongan 25%.

Data/tarif/dokumen adalah ilustrasi dan tidak boleh diperlakukan sebagai data operasional atau dokumen dinas yang sah. Semua batasan terperinci dan skenario demonstrasi ada di README.md.

Pembaruan: editor/pratinjau SKRD, STS dan STBP; unggah lokal berkas persyaratan, dokumen manual dan bukti bayar; riwayat hapus/pulihkan; cadangan metadata arsip; edit profil demo. Rincian dan perbedaan dari referensi ada di docs/AUDIT-FITUR-REFERENSI.md.
